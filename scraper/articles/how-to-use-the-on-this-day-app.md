# How to Use the On This Day App
**Source:** https://support.optisigns.com/hc/en-us/articles/1500009492202-How-to-Use-the-On-This-Day-App

The On This Day app provides small trivia information by getting highlights from Wikipedia's database of what happens on this date. Usually it's birthday a birthday, some historical events, or some sort of worldwide holiday. This works as fun filler content for digital signs.

Here's how it will look.
* Not all events have pictures

 

First, you will need to have your screens set up and paired. For more information on how to do that, click [here](https://support.optisigns.com/hc/en-us/articles/18823504383891-OptiSigns-Getting-Started-Guide).

Then log on to our portal: [https://app.optisigns.com/](http://app.optisigns.com/)
